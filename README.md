# Paperroom

A browser studio for stickers, pins, cards, gift tags, and box dielines. Write one sentence, adjust the sheet by clicking it, and download an SVG with cut lines, folds, and bleed.

21 October 2026's top Product Hunt launch was UseIt Studio, a design tool that turns a sentence into an editable file for something you can print and hold. Paperroom is an original app for that kind of sheet. It is not affiliated with UseIt Studio.

Open `index.html` in a browser. Nothing to install.
